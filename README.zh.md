<a id="about"></a>

## 简介

FastCollageForWin 把一堆照片合成一张图。把照片添加到左侧面板，手动摆到画布上或放进自动生成的网格，逐张调整（缩放、平移、旋转、镜像），最后导出为一个 PNG 或 JPEG 文件。

它是用 Python 和 PySide6（Qt 6）写的桌面程序，通过 PyInstaller 打包成单个无控制台的 Windows 可执行文件。

两种工作方式：

- **自由拼贴** — 每张照片都是独立对象，可在画布上任意移动、缩放和旋转。
- **随机拼贴** — 程序生成一组格子；拖入格子的照片会填满它，格子之间的边界可以拖动，用来重新分配空间。

**适合谁：**

- 想快速做出干净拼图、又不想打开完整修图软件的人；
- 需要准备版式和预览图的设计师与摄影师；
- 制作相册、海报、封面图或社交媒体配图的人。

<a id="features"></a>

## 功能

- 两种拼贴模式：自由摆放，以及带可拖动分隔线的自动生成网格。
- **根据照片推算画布**（`Ctrl+Shift+A`）：程序会根据所选照片计算画布尺寸和排版，提供两种模式——精确比例，或带裁切预算并给出多个候选排版。
- 逐张编辑：缩放、平移、自由旋转、水平与垂直镜像、图层顺序。
- 拼贴样式：照片间距、圆角半径、背景颜色或完全透明背景。
- 25 个画布预设，分为屏幕、社交平台和打印（A5–A3 以及 300 dpi 的照片尺寸），也可自定义 100 到 10000 px 的任意尺寸。
- 导出 PNG 或 JPEG，缩放 10–400 %，带 JPEG 质量滑块，保存前显示文件体积估算，并按条带渲染，因此超大画布的内存占用保持平稳。
- 项目文件（`.fcproj`，内部为 JSON）保存图片的**相对路径**：整个文件夹搬走后仍能打开，缺失的文件可以重新关联。
- 撤销与重做，默认 100 步。
- 图片在后台线程池中加载，进度可取消。
- 图片面板支持从资源管理器拖入、显示缩略图，并可把画布上的照片送回面板。
- 剪贴板：复制、粘贴与生成副本。
- 五种界面语言——英语、俄语、西班牙语、中文和阿拉伯语，阿拉伯语采用从右到左布局。
- 快捷键在任何键盘布局下都有效：模式键按物理扫描码读取。
- 日志文件自动轮换：任何静默错误都会留下痕迹。
- 网格里每张照片都会裁切到自己的格子内：照片之间不会重叠，网格铺满整张画布，唯一的空隙就是你设定的间距。
- 自由拼图不限制照片数量，上限只有内存。
- 图片面板是可停靠面板：**视图 → 预览面板** 可隐藏或显示它，面板能浮动、可一键清空，状态会在下次启动时恢复。**文件 → 载入面板** 只把照片放进面板，不会放到画布上。

<a id="requirements"></a>

## 环境要求

- **Windows 10 或 11。** 程序面向 Windows：日志路径和与键盘布局无关的快捷键都基于它，其余部分是纯 Python 和 Qt。
- **Python 3.9 及以上**
- **PySide6**（Qt 6）——唯一的运行时依赖。

<a id="install"></a>

## 安装与运行

```powershell
git clone https://github.com/re-quies/fastcollageforwin
cd fastcollageforwin
python -m venv .venv
.venv\Scripts\activate
pip install PySide6
python main.py
```

<a id="build"></a>

## 打包成 exe

```powershell
pip install pyinstaller
pyinstaller main.spec
```

spec 文件会生成单个无控制台的可执行文件（`console=False`），并把 `assets/` 目录一起打包，因此图标不会丢失。结果是 `dist/main.exe`，可以随意改名。

窗口标题中的版本号来自 `core/version.py`。如果打包后标题仍显示旧版本，说明 PyInstaller 用了过期文件——问题在打包，不在代码。

<a id="quickstart"></a>

## 快速上手

1. 启动程序。在**新建拼图**对话框中选择模式（自由或随机）、网格所需的照片数量，以及画布尺寸（预设或自定义宽高）。
2. 添加照片：**文件 → 添加图片**（`Ctrl+O`），或从资源管理器把文件拖入图片面板。
3. 把面板中的缩略图拖到画布上，或拖进网格的格子里。
4. 调整照片：按住 `Z` 滚动滚轮缩放内容，按住 `C` 拖动在格子内移动，按住 `R` 拖动旋转。按 `X` 把选中的照片送回面板。
5. 外观在**画布 → 间距和背景**中调整：照片间距、圆角半径、背景颜色或透明。
6. 导出：**文件 → 导出**（`Ctrl+E`），选择 PNG 或 JPEG、缩放比例和质量。

<a id="autofit"></a>

## 根据照片推算画布

**画布 → 按照片适配画布**（`Ctrl+Shift+A`）会读取面板中的照片，直接给出画布尺寸和排版，不需要你先猜一个尺寸。尺寸可按需取整：精确尺寸、取整到 10 px、取整到 100 px，或自动取整数。

两种适配模式：

- **精确比例（不裁切）** — 每张照片保留原有比例，不会裁掉任何部分，给出一个最优排版。
- **更多方案（裁切最多 N %）** — 每张照片最多可失去一条边的 N %，比例因此能向便于排版的目标靠近，从而解锁几十种不同网格，并按优劣排序；**换一种网格**按钮逐个切换，计数器显示“方案 3 / 12”。

裁切额度和方案数量在**设置 → 画布适配设置**中调整（0–50 % 与 2–48，默认 20 % 和 12）。它们只影响第二种模式，第一种模式不受影响。

裁切额度并非越大越好：大约超过 35 % 之后，不同照片会被拉向相同的目标比例，排版开始重复，独特网格的数量反而下降。最佳区间是 20–35 %。

<a id="export"></a>

## 导出

**文件 → 导出**（`Ctrl+E`）生成单个 PNG 或 JPEG 文件。

- 预设缩放比例：10、25、50、75、100、150、200、300、400 %。
- JPEG 质量滑块，默认 92。
- 对话框在保存前就显示像素尺寸和文件体积估算。
- 安全上限：单边超过 32000 px 或估算超过 2 GB 会被拒绝，超过 512 MB 会要求确认。
- 渲染按 2048 px 高的横向条带进行，因此超大画布也不需要整幅高度的位图常驻内存。
- PNG 保留透明背景；JPEG 不支持透明，会将其压平。
- 以 100% 比例导出时，图片的像素尺寸与画布完全一致，可直接用于打印或上传。

<a id="projects"></a>

## 项目、设置与日志

- 项目保存为 `.fcproj`（内部是 JSON）；旧版本的 `.json` 也能打开。
- 图片路径按**相对于项目文件**的方式保存，整个文件夹搬走也不会破坏拼图。绝对路径作为后备保留。
- 打开时若有图片缺失，程序会提示指定新文件夹重新链接。
- 最近 8 个项目列在**文件 → 最近的项目**中。
- 设置通过 `QSettings`（Windows 注册表）保存：界面语言、窗口几何、撤销步数上限、导出比例与质量、画布适配参数，以及最近使用的文件夹。
- 日志位于 `%LOCALAPPDATA%\FastCollageForWin\fastcollage.log`，2 MB 轮换、保留 5 份。打包后的程序没有控制台，所以日志是查看意外错误的唯一位置；错误对话框会显示它的路径。

<a id="limits"></a>

## 限制

- 画布单边：100–10000 px（最大约 1 亿像素）。
- 新建拼图对话框接受 1–100 张照片。
- 画布适配在 20 张照片以内穷举完整的排版树，超过则改用简化方案。
- 导出：单边最多 32000 px，单个文件约 2 GB。
- 可导入的格式：PNG、JPG、JPEG、BMP、WEBP。
